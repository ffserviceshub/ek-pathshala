# Ek Course — GitHub Pages starter

This is an original starter website inspired by the general folder organization of a course website. It does not copy the source code or assets of PremiumSubscriptions/ps.

## Structure
- `index.html` — home page
- `about/` — about page
- `class/` — classes
- `contact/` — contact details
- `courses/` — course listing
- `exam/` — exam preparation
- `free/` — free learning resources
- `login/` — login placeholder
- `assets/` — CSS and JavaScript
- `logo.webp` — starter logo

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
3. Wait for the Pages deployment to complete.

## Important
GitHub Pages is static hosting. A real login system, paid course checkout, private video access, or working server-side contact form needs an external service/backend. Replace the sample contact details and course content before publishing.
